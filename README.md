# ☕ فروشگاه اینترنتی قهوه آروما (Aroma Coffee)

یک وب‌سایت مدرن، سریع و واکنش‌گرا (Responsive) برای فروشگاه آنلاین قهوه که با استفاده از **React**، **Vite** و **Tailwind CSS** پیاده‌سازی شده است. این پروژه شامل بخش‌های مختلفی از جمله لیست محصولات، جزئیات محصول، سبد خرید، سیستم ثبت دیدگاه، وبلاگ و صفحه تماس با ما می‌باشد.

---

## 🚀 ویژگی‌های کلیدی (Features)

* **طراحی مدرن و زیبا:** رابط کاربری شیک و کاربرپسند با استفاده از قدرت **Tailwind CSS**
* **مدیریت وضعیت هوشمند (Context API):**
  * `CartContext`: مدیریت افزودن، حذف و تغییر تعداد محصولات در سبد خرید
  * `ReviewsContext`: قابلیت مشاهده و ثبت نظرات جدید برای محصولات
  * `SearchContext`: جستجوی سریع و هوشمند در میان محصولات
* **انیمیشن‌ها و جلوه‌های بصری:** استفاده از کامپوننت‌های سفارشی انیمیشن (`FadeIn`) جهت بهبود تجربه کاربری (UX)
* **پشتیبانی کامل از فونت فارسی:** استفاده از فونت استاندارد **ایران‌سانس (IranSans)**
* **کاملاً واکنش‌گرا (Responsive):** نمایش بهینه در تمامی دستگاه‌ها (موبایل، تبلت و دسکتاپ)
* **پیمایش سریع (ScrollToTop):** انتقال خودکار کاربر به بالای صفحه هنگام تغییر مسیرها

Aroma/

└── src/
    ├── assets/             # آیکون‌ها و منابع گرافیکی

    ├── pages/              # صفحات اصلی (Home, Products, ProductDetail, Cart, Blog, ...)
    ├── utils/              # توابع و ابزارهای کمکی
    ├── App.jsx             # پیکربندی روت‌ها و ساختار اصلی
    └── main.jsx            # نقطه ورود برنامه
